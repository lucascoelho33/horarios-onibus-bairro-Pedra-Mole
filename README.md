# MVP - Horários de Ônibus do Bairro Pedra Mole

API RESTful para consulta de horários de ônibus do bairro Pedra Mole.

## Tecnologias
- Node.js
- Express
- Supabase (PostgreSQL)

## Como rodar
1. Clone o repositório
2. Instale as dependências: `npm install`
3. Crie um arquivo `.env` baseado no `.env.example`
4. Rode: `node src/server.js`
