# horarios-onibus-bairro-Pedra-Mole
Para moradores do bairro Pedra Mole que sofrem com a falta de informação confiável sobre horários de ônibus, faremos um painel mobile simples com os horários previstos das linhas do bairro, diferente de grupos de WhatsApp desatualizados e placas ilegíveis, medindo o sucesso por 30 consultas no primeiro mês.
